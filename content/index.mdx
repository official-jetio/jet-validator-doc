# @jetio/validator

Compiles JSON Schema into specialized JavaScript validation functions. Around **14x faster compilation** than AJV on average, **99%+ compliance** from Draft 06 to 2020-12, and **zero-runtime standalone** output that runs with no library and no `new Function()`.

## Why it's different

Most validators keep your schema and interpret it on every call. @jetio/validator reads the schema once and emits straight-line JavaScript specialized to that exact shape — property loops, type checks, and `$ref` calls unrolled into a single function. That one idea is what makes compilation fast enough to run per request, and it's what lets the same engine emit a standalone module you can ship to production.

- **~14x faster compilation** — sub-millisecond for most schemas, faster on every schema in the [benchmark suite](https://github.com/official-jetio/validator/blob/main/benchmark.md)
- **99%+ spec compliant** — Draft 06, 07, 2019-09, and 2020-12, measured against the official JSON Schema Test Suite
- **Zero-runtime standalone** — emit plain validation functions for strict CSP, edge runtimes, and Workers
- **Zero dependencies**, ~39kB gzipped with built-in formats and error messages
- **`elseIf`, `$data`, custom keywords and formats** included, no extra packages
- **Familiar API** — close to AJV's `compile` / `validate` shape

## Quick start

```typescript
import { JetValidator } from "@jetio/validator";

const jetValidator = new JetValidator({ allErrors: true });

const schema = {
  type: "object",
  required: ["name", "age"],
  properties: {
    name: { type: "string", minLength: 2 },
    age: { type: "number", minimum: 0, maximum: 120 },
    email: { type: "string", format: "email" },
  },
};

const validate = jetValidator.compile(schema);

validate({ name: "Alice", age: 25, email: "alice@example.com" }); // true
validate({ name: "A", age: 150 }); // false

console.log(validate.errors);
// [
//   { dataPath: "/name", keyword: "minLength", message: "must have at least 2 characters." },
//   { dataPath: "/age",  keyword: "maximum",   message: "must be <= 120" }
// ]
```

The exact error objects are shown live in the [playground](/playground) — paste any schema and data to see what your build emits.
